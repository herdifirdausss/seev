# K0 resource evidence

Store bounded per-profile resource samples here. Samples must identify the
disposable Compose project and keep observability overhead separate from the
application baseline.

R0, R1, and R2 are bounded samples, not the roadmap's 10-minute stabilization
claim. The superseded first R1 capture was intentionally retained as a
diagnostic artifact; it sampled only one Compose container before the sampler
filter was corrected. Use `R1-20260802T235223Z.csv` for the K0 result.
